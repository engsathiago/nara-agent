# Procedência upstream

Nara é um projeto independente derivado de
[Hermes Agent](https://github.com/NousResearch/hermes-agent), versão 0.23.1, no commit
`3b421578588243f920886e6fe79a6faa87ea026e`, sob licença MIT.

Este arquivo é a única referência de identidade da base no conjunto de documentação operacional.
O nome upstream não é comando, pacote, namespace, caminho de estado, endpoint próprio nem marca da
Nara. Repositórios de plugins e pesquisas externas conservam seus nomes reais para manter
procedência, licenças e instalações reproduzíveis.
